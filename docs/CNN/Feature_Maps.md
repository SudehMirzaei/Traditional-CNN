# Feature Maps in CNNs

## 1. Introduction

A **Feature Map** is one of the fundamental outputs of a convolutional layer in a Convolutional Neural Network (CNN).

A feature map represents the spatial responses produced when a learned filter is applied to an input.

The basic process is:

```text
Input
  ↓
Learned Filter
  ↓
Convolution
  ↓
Feature Map

A feature map tells us:

> Where and how strongly a particular learned pattern is detected in the input.
```

Feature maps are therefore an important part of the internal representation learned by CNNs.

---

## 2. From Image to Feature Map

Suppose the input is a grayscale image:

```
28 × 28 × 1
```

and we apply one convolutional filter:

```
3 × 3
```

The filter moves across the image.

At each position:

```
Local Image Region
        ↓
Element-wise Multiplication
        ↓
Summation
        ↓
One Activation
```

Repeating this process across the entire image produces many activation values.

These values are arranged spatially:

```
┌───────────────────────┐
│ 0.1  0.2  0.5  0.8   │
│ 0.0  0.4  0.7  0.9   │
│ 0.1  0.3  0.6  0.8   │
│ 0.0  0.2  0.5  0.7   │
└───────────────────────┘
```

This matrix is a Feature Map.

---

## 3. Feature Map vs Filter

These two concepts are often confused.

### Filter

A filter contains learnable weights.

For example:

```
3 × 3
```

or for an RGB input:

```
3 × 3 × 3
```

The filter is the learned pattern detector.

### Feature Map

A feature map is the output generated by applying that filter across the input.

Therefore:

```
Filter
  ↓
Convolution
  ↓
Feature Map
```

In simple terms:

> The filter is the detector; the feature map is the detector's response across the image.

---

## 4. One Filter Produces One Feature Map

Suppose a convolutional layer contains only one filter:

```
Input
  ↓
Filter 1
  ↓
Feature Map 1
```

The output therefore contains one feature map.

For example:

```
Input: 224 × 224 × 3
        ↓
3 × 3 Conv
1 Filter
        ↓
Feature Map: 224 × 224
```

assuming the convolution uses padding and stride that preserve the spatial dimensions.

---

## 5. Multiple Filters Produce Multiple Feature Maps

A convolutional layer normally contains many filters.

For example:

```
64 Filters
```

means that the layer learns 64 different sets of weights.

Each filter produces one feature map:

```
Input
  │
  ├── Filter 1  ──→ Feature Map 1
  ├── Filter 2  ──→ Feature Map 2
  ├── Filter 3  ──→ Feature Map 3
  │
  ├── ...
  │
  └── Filter 64 ─→ Feature Map 64
```

Therefore:

\[
\boxed{
\text{Number of Filters}
=
\text{Number of Feature Maps}
}
\]

and:

\[
\boxed{
\text{Number of Feature Maps}
=
\text{Number of Output Channels}
}
\]

---

## 6. Example: 64 Feature Maps

Suppose:

```
Input: 224 × 224 × 3
```

and the convolutional layer has:

```
64 Filters
```

with:

```
3 × 3
```

kernel size.

If padding and stride preserve the spatial dimensions, the output becomes:

```
224 × 224 × 64
```

This means:

```
64 Feature Maps
```

where every feature map is:

```
224 × 224
```

Conceptually:

```
224 × 224 × 64
      ↓
┌─────────────────────┐
│ Feature Map 1       │ 224 × 224
├─────────────────────┤
│ Feature Map 2       │ 224 × 224
├─────────────────────┤
│ Feature Map 3       │ 224 × 224
├─────────────────────┤
│ ...                 │
├─────────────────────┤
│ Feature Map 64      │ 224 × 224
└─────────────────────┘
```

---

## 7. What Does a Feature Map Contain?

A feature map contains numerical activation values.

For example:

```
┌──────┬──────┬──────┬──────┐
│ 0.1  │ 0.2  │ 0.8  │ 0.9  │
├──────┼──────┼──────┼──────┤
│ 0.0  │ 0.4  │ 0.7  │ 0.8  │
├──────┼──────┼──────┼──────┤
│ 0.1  │ 0.3  │ 0.6  │ 0.9  │
└──────┴──────┴──────┴──────┘
```

Each number corresponds to a spatial location.

For example:

```
0.9
```

means the learned filter produced a strong response at that particular location.

A small value such as:

```
0.1
```

means the response was weaker.

---

## 8. Activation Strength

The numerical values in a feature map are called activations.

Conceptually:

```
Large Activation
       ↓
Strong Response
       ↓
Pattern strongly detected

Small Activation
       ↓
Weak Response
       ↓
Pattern weakly detected
```

Therefore, feature maps contain information about both:

1. Where a pattern occurs.
2. How strongly the filter responds to it.

This spatial information is one of the most important properties of CNNs.

---

## 9. Feature Maps as Spatial Maps

Consider a filter that has learned to detect vertical edges.

Suppose the image contains a vertical edge around the center:

```
Image
███████│░░░░░░░
███████│░░░░░░░
███████│░░░░░░░
███████│░░░░░░░
```

The corresponding feature map might show strong activations around the edge location:

```
┌─────────────────┐
│ 0  0  0  0  0  │
│ 0  0  8  0  0  │
│ 0  0  9  0  0  │
│ 0  0  8  0  0  │
└─────────────────┘
```

The high values indicate where the filter detected its learned pattern.

---

## 10. Feature Map Is Not a New Image

A feature map may look like an image because it is a two-dimensional grid of values.

However, it is not necessarily a normal image.

An original image may represent:

- Pixel Intensity
- Color

while a feature map represents:

- Response of a Learned Filter

For example:

```
Original Image
      ↓
Pixel Values

Feature Map
      ↓
Learned Feature Responses
```

Therefore, feature maps are better understood as internal representations rather than ordinary images.

---

## 11. Feature Maps and Channels

Suppose the output tensor is:

```
56 × 56 × 64
```

This means:

- Height = 56
- Width  = 56
- Channels = 64

The 64 channels correspond to:

- Feature Map 1
- Feature Map 2
- Feature Map 3
- ...
- Feature Map 64

Each channel is therefore a two-dimensional feature map:

```
56 × 56
```

So:

```
56 × 56 × 64
```

can be interpreted as:

> 64 different feature maps, each containing a 56 × 56 spatial grid of activations.

---

## 12. Why Do We Need Many Feature Maps?

One filter cannot detect every possible visual pattern.

For example, different filters can learn different responses:

- Filter 1 → Horizontal patterns
- Filter 2 → Vertical patterns
- Filter 3 → Diagonal patterns
- Filter 4 → Corners
- Filter 5 → Texture
- Filter 6 → Color transitions
- ...

Therefore, multiple filters allow the network to learn multiple types of information simultaneously.

Conceptually:

```
Input
  ↓
┌──────────────────────────┐
│ Filter 1 → Pattern A     │
│ Filter 2 → Pattern B     │
│ Filter 3 → Pattern C     │
│ Filter 4 → Pattern D     │
│ ...                      │
└──────────────────────────┘
  ↓
Multiple Feature Maps
```

---

## 13. Feature Maps in Early Layers

Early convolutional layers are close to the raw image.

They often learn relatively simple visual patterns such as:

- Edges
- Corners
- Intensity transitions
- Simple textures
- Color patterns

For example:

```
Input Image
     ↓
First Conv Layer
     ↓
Feature Maps
     ↓
Edges / Simple Patterns
```

A feature map in an early layer may therefore respond strongly to particular edge orientations or simple textures.

---

## 14. Feature Maps in Middle Layers

As the network becomes deeper, the feature maps become representations of more complex combinations of earlier features.

For example:

```
Early Layers
     ↓
Edges
     ↓
Middle Layers
     ↓
Textures + Shapes
```

A middle-layer feature map may respond to a more complex pattern that is composed of several simpler features.

For example:

```
Edges
 + 
Corners
 +
Texture
 ↓
Complex Local Pattern
```

---

## 15. Feature Maps in Deep Layers

Deep convolutional layers can represent increasingly complex patterns.

Conceptually:

```
Pixels
  ↓
Edges
  ↓
Textures
  ↓
Shapes
  ↓
Object Parts
  ↓
High-Level Representation
```

Therefore, deep feature maps often contain more abstract information than early feature maps.

However, it is important to remember:

> A single deep feature map does not necessarily correspond to one complete semantic concept.

Representations in deep networks are often distributed across multiple channels.

---

## 16. Hierarchical Feature Representation

Feature maps demonstrate how CNNs build hierarchical representations.

A simplified example:

```
Layer 1
────────
Feature Maps
    ↓
Edges

Layer 2
────────
Feature Maps
    ↓
Textures

Layer 3
────────
Feature Maps
    ↓
Shapes

Layer 4
────────
Feature Maps
    ↓
Complex Structures

Layer 5
────────
Feature Maps
    ↓
High-Level Representation
```

Each layer receives feature maps from the previous layer and transforms them into new feature maps.

---

## 17. Feature Maps Across Layers

Suppose we have:

```
Input: 224 × 224 × 3
```

After the first convolution:

```
224 × 224 × 64
```

After downsampling:

```
112 × 112 × 64
```

A deeper layer may produce:

```
112 × 112 × 128
```

Later:

```
56 × 56 × 256
```

Then:

```
28 × 28 × 512
```

The network is gradually changing the representation.

A common pattern is:

```
Spatial Resolution ↓
Number of Channels ↑
```

For example:

```
224 × 224 × 64
        ↓
112 × 112 × 128
        ↓
56 × 56 × 256
        ↓
28 × 28 × 512
```

---

## 18. Why Does Spatial Resolution Decrease?

As the network becomes deeper, it often reduces spatial resolution using:

- Pooling
- Strided Convolution

For example:

```
56 × 56
    ↓
28 × 28
```

This reduces computational cost.

It also allows deeper layers to have larger effective receptive fields.

Therefore, deeper feature maps can represent information from larger regions of the original image.

---

## 19. Why Do Channels Increase?

When spatial resolution decreases, CNN architectures often increase the number of channels.

For example:

```
56 × 56 × 128
        ↓
28 × 28 × 256
```

Although there are fewer spatial positions, the network has more channels available to store different learned features.

Conceptually:

```
Spatial Detail
      ↓
Reduced

Feature Diversity
      ↓
Increased
```

This is a common design principle in deep CNNs.

---

## 20. Feature Maps and Information

Feature maps should not be thought of as simply "images with fewer pixels."

They contain transformed information.

For example:

```
Original Image
     ↓
Pixel Information
```

while:

```
Feature Map
     ↓
Learned Pattern Information
```

A deeper feature map can encode combinations of patterns that are not directly visible in the original image.

Therefore, feature maps are part of the network's learned internal representation.

---

## 21. Feature Maps After ReLU

In many CNN architectures, convolution is followed by an activation function such as ReLU:

```
Convolution
     ↓
ReLU
     ↓
Feature Map
```

ReLU is:

\[
ReLU(x)=\max(0,x)
\]

Therefore:

```
Negative Activation
       ↓
0

Positive Activation
       ↓
Unchanged
```

For example:

```
Before ReLU:
[-2, -1, 0, 2, 5]

After ReLU:
[0, 0, 0, 2, 5]
```

The resulting feature map contains non-negative activations.

---

## 22. Feature Maps and Batch Normalization

In architectures that use Batch Normalization, the sequence may be:

```
Convolution
     ↓
Batch Normalization
     ↓
ReLU
     ↓
Feature Map
```

Batch Normalization normalizes activations during training and can help stabilize optimization.

The feature map after the activation represents the transformed output that is passed to subsequent layers.

---

## 23. Feature Maps and Receptive Fields

Each activation in a feature map corresponds to a particular region of the previous layer.

That region is related to the activation's receptive field.

Early feature maps:

```
Small Receptive Field
```

Deep feature maps:

```
Larger Receptive Field
```

Conceptually:

```
Input Image
┌─────────────────────────────┐
│                             │
│      Small Region           │
│         ↓                   │
│       Activation            │
│                             │
└─────────────────────────────┘
```

After several layers:

```
Input Image
┌─────────────────────────────┐
│                             │
│   ┌─────────────────────┐   │
│   │   Larger Region     │   │
│   │         ↓           │   │
│   │     Activation      │   │
│   └─────────────────────┘   │
│                             │
└─────────────────────────────┘
```

Therefore, deeper feature maps can integrate information from larger portions of the original input.

---

## 24. Visualizing Feature Maps

Feature maps can be visualized to investigate what a CNN has learned.

For example:

```
Input Image
     ↓
CNN Layer
     ↓
Extract Feature Maps
     ↓
Visualize Activations
```

A feature map can be displayed as a grayscale or heatmap-like image.

Conceptually:

```
Feature Map

Low Activation
░░░░░░░░

Medium Activation
▒▒▒▒▒▒▒▒

High Activation
████████
```

Bright regions can represent stronger activations depending on the visualization convention.

---

## 25. Why Visualize Feature Maps?

Feature map visualization can help us investigate:

- What patterns a layer responds to
- Where activations occur
- How representations change with depth
- Whether a layer is responding to meaningful image regions
- Whether certain filters are inactive
- How different filters behave

It can therefore be useful for understanding CNN representations.

---

## 26. Feature Map Visualization vs Grad-CAM

Feature map visualization and Grad-CAM are related but different.

### Feature Map Visualization

Directly examines activations produced by a particular layer.

```
Input
  ↓
CNN Layer
  ↓
Feature Map
  ↓
Visualization
```

It answers questions such as:

> What does this filter respond to?

### Grad-CAM

Grad-CAM uses gradients to identify image regions that are important for a particular prediction.

```
Input
  ↓
CNN
  ↓
Prediction
  ↓
Gradients
  ↓
Grad-CAM
  ↓
Importance Map
```

Therefore:

- **Feature Maps** → Internal Activations
- **Grad-CAM** → Class-specific Importance

## 27. Feature Maps in ResNet

ResNet uses feature maps throughout its convolutional layers.

For example, a simplified ResNet50 progression is:

```
Input: 224 × 224 × 3
      ↓
Initial Conv
112 × 112 × 64
      ↓
Max Pool
56 × 56 × 64
      ↓
Residual Stage 1
56 × 56 × 256
      ↓
Residual Stage 2
28 × 28 × 512
      ↓
Residual Stage 3
14 × 14 × 1024
      ↓
Residual Stage 4
7 × 7 × 2048
```

The exact tensor dimensions depend on the specific layer being considered, but the overall architectural principle is:

```
Spatial Resolution ↓
Channels ↑
```

---

## 28. Feature Maps Inside a ResNet Bottleneck

Consider a ResNet50 Bottleneck Block.

Suppose the input is:

```
56 × 56 × 256
```

The first 1 × 1 convolution reduces the channels:

```
56 × 56 × 256
       ↓
1 × 1 Conv
       ↓
56 × 56 × 64
```

The 3 × 3 convolution processes these 64-channel feature maps:

```
56 × 56 × 64
       ↓
3 × 3 Conv
       ↓
56 × 56 × 64
```

The final 1 × 1 convolution expands the representation:

```
56 × 56 × 64
       ↓
1 × 1 Conv
       ↓
56 × 56 × 256
```

Therefore, the feature maps are continuously transformed throughout the bottleneck.

---

## 29. Feature Maps and Channel Mixing

A convolution does not simply process each channel independently.

For a standard convolution, each output feature map combines information from all input channels.

For example:

```
Input Channels

Channel 1 ─┐
Channel 2 ─┤
Channel 3 ─┤
Channel 4 ─┤
...        ├──→ Filter → Output Feature Map
Channel N ─┘
```

Therefore, an output feature map contains information derived from multiple input channels.

This is especially important in deeper CNN layers, where each channel already represents a learned feature.

---

## 30. Feature Maps as Tensors

A convolutional layer's output is usually represented as a tensor.

For a single image:

```
H × W × C
```

where:

- \(H\) = Height
- \(W\) = Width
- \(C\) = Number of Channels / Feature Maps

For example:

```
56 × 56 × 256
```

means:

- 56 × 56 spatial positions
- 256 feature channels

or equivalently:

- 256 Feature Maps

each of size:

```
56 × 56
```

---

## 31. Batch Dimension

In actual deep learning frameworks such as PyTorch, tensors usually include a batch dimension.

For example:

```
Batch × Channels × Height × Width
```

A tensor may have:

```
32 × 64 × 56 × 56
```

This means:

- 32 images
- 64 feature channels
- 56 × 56 spatial dimensions

For each image:

```
64 Feature Maps
```

are produced.

Therefore:

- Batch Size = 32
- Channels = 64
- Height = 56
- Width = 56

---

## 32. Feature Maps and Representation Learning

Feature maps are one of the main forms of internal representation in CNNs.

The network gradually transforms:

```
Raw Pixels
     ↓
Low-Level Feature Maps
     ↓
Mid-Level Feature Maps
     ↓
High-Level Feature Maps
     ↓
Final Representation
```

This process is called Representation Learning.

The network learns how to transform the original input into representations that are useful for the final task.

---

## 33. Feature Maps Are Learned, Not Hand-Crafted

In traditional computer vision:

```
Image
  ↓
Human-designed Feature Extraction
  ↓
Feature Vector
```

In CNNs:

```
Image
  ↓
Learned Convolutional Filters
  ↓
Feature Maps
  ↓
Learned Representation
```

The CNN learns the filters and therefore learns how to construct its feature maps.

This is a fundamental difference between manual feature engineering and deep representation learning.

---

## 34. Feature Map Example

Suppose a convolutional layer receives:

```
Input: 32 × 32 × 3
```

and contains:

```
16 Filters
```

with:

```
3 × 3 Kernel
Stride = 1
Padding = 1
```

The output spatial dimensions remain:

```
32 × 32
```

and the number of channels is:

```
16
```

Therefore:

```
Input: 32 × 32 × 3
       ↓
Convolution
16 Filters
       ↓
Output: 32 × 32 × 16
```

This means:

- Feature Map 1  → 32 × 32
- Feature Map 2  → 32 × 32
- ...
- Feature Map 16 → 32 × 32

---

## 35. Important Conceptual Distinction

When we say:

```
64 Feature Maps
```

we do not mean:

```
64 completely separate images
```

Instead, we mean:

> The convolutional layer has produced 64 different spatial representations of the same input, each generated by a different learned filter.

Each feature map emphasizes different learned patterns.

Therefore:

```
Same Input
     ↓
Different Filters
     ↓
Different Feature Maps
     ↓
Different Learned Information
```

---

## 36. Feature Maps and Information Compression

As CNNs become deeper, spatial dimensions often decrease.

For example:

```
224 × 224 × 64
       ↓
112 × 112 × 128
       ↓
56 × 56 × 256
       ↓
28 × 28 × 512
       ↓
14 × 14 × 1024
       ↓
7 × 7 × 2048
```

The network loses some fine-grained spatial resolution but gains more channels.

This allows the representation to shift from:

- Detailed Spatial Information

toward:

- Rich High-Level Feature Information

---

## 37. Feature Maps and Global Average Pooling

Near the end of many CNN architectures, feature maps are converted into a compact representation using Global Average Pooling (GAP).

Suppose the final convolutional output is:

```
7 × 7 × 2048
```

This means:

- 2048 Feature Maps

each of size:

```
7 × 7
```

Global Average Pooling computes the average of each feature map:

```
7 × 7 Feature Map
       ↓
One Average Value
```

Therefore:

```
7 × 7 × 2048
       ↓
Global Average Pooling
       ↓
2048-dimensional Vector
```

This vector can then be passed to a classifier.

---

## 38. Feature Maps and Classification

The overall process can therefore be represented as:

```
Input Image
     ↓
Convolutional Layers
     ↓
Feature Maps
     ↓
Deeper Feature Maps
     ↓
Global Average Pooling
     ↓
Feature Vector
     ↓
Fully Connected Layer
     ↓
Class Prediction
```

The classifier does not usually operate directly on the raw pixels.

Instead, it uses the learned representation produced by the convolutional layers.

---

## 39. Feature Maps and Explainability

Feature maps are also useful for analyzing neural networks.

For example, researchers may inspect:

- Early Feature Maps

to understand low-level visual responses and:

- Deep Feature Maps

to understand higher-level representations.

This can be combined with other explainability methods such as:

- Grad-CAM
- Grad-CAM++
- Integrated Gradients
- Activation Maximization
- Feature Visualization

These methods provide different perspectives on what the network has learned.

---

## 40. Summary

A Feature Map is a spatial representation produced by applying a learned filter to an input.

The fundamental relationship is:

```
Filter
   ↓
Convolution
   ↓
Feature Map
```

One filter produces one feature map:

\[
\boxed{
1\ Filter \rightarrow 1\ Feature\ Map
}
\]

Multiple filters produce multiple feature maps:

\[
\boxed{
N\ Filters \rightarrow N\ Feature\ Maps
}
\]

The output tensor therefore has:

```
Height × Width × Number of Filters
```

For example:

```
56 × 56 × 64
```

means:

- 64 Feature Maps

where each feature map has dimensions:

```
56 × 56
```

Feature maps contain activation values that indicate where and how strongly learned patterns are detected.

The overall learning process is:

```
Raw Image
    ↓
Convolutional Filters
    ↓
Feature Maps
    ↓
Low-Level Features
    ↓
Higher-Level Features
    ↓
Deep Representation
    ↓
Prediction
```

Therefore, feature maps are a fundamental component of CNN-based representation learning.

---

## 41. Key Takeaways

- A feature map is the output of a convolutional filter.
- One filter produces one feature map.
- Multiple filters produce multiple feature maps.
- The number of filters equals the number of output channels.
- A feature map contains spatial activation values.
- Strong activations indicate strong responses to the learned pattern.
- Feature maps preserve spatial information.
- Early feature maps often represent simple patterns.
- Deeper feature maps represent increasingly complex combinations of features.
- A feature map is not simply another image; it is an internal learned representation.
- Standard convolutions combine information across input channels.
- Feature maps are usually represented as tensors in deep learning frameworks.
- In PyTorch, convolution outputs commonly follow the format: Batch × Channels × Height × Width.
- Global Average Pooling can transform spatial feature maps into a compact feature vector.
- Feature maps are useful for representation analysis and explainability.
- Feature maps are one of the main mechanisms through which CNNs perform hierarchical representation learning.
